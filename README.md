# 抽砖不倒 · 24 个立体关卡

叠叠高与托盘三消结合的竖屏小游戏：轻点抽砖，三根同色消除；左右拖动转动视角，保留支撑，别让模型倒塌。

在线试玩：https://2324621372.github.io/jengamatch-play/

24 个独立立体造型，包括汽车、恐龙、城堡，以及新增的灯塔、蘑菇、风车、企鹅、大象、海龟、帆船、火车、飞机、机器人、茶壶、双拱桥、宝塔、相机、飞碟和宝箱。点击左上角四宫格，通过三页关卡地图选择关卡。
